# Scene-Based Awwwards Redesign

## Core creative shift

- Removed the remaining terminal, system-status and dashboard language from the visible portfolio.
- Replaced one continuous navy interface with a sequence of distinct visual worlds.
- Introduced an editorial sans/serif identity, stronger scale contrast and calmer navigation.
- Removed the opening loader and custom cursor so access to the work is immediate.

## Flagship storytelling

### Indus Agent

- Replaced the redacted confidential interface with a public, honest description of the current system.
- Added an interactive Goal → Plan → Act → Verify → Remember sequence.
- Clarified implemented capabilities and separated them from the long-term AI Engineering OS direction.

### NIFTY 50 Research Engine

- Replaced the audit dashboard with a visual signal journey.
- Added three accessible research views: raw data, walk-forward testing and execution reality.
- Kept the public break-even friction, claim boundaries and source artifacts visible.

### Recurrent PPO MotoSim

- Reframed the replay as a cinematic mountain scene instead of a telemetry console.
- Preserved deterministic source-derived behaviour and honest benchmark provenance.
- Added responsive live progress, engine-memory and replay controls.

## Supporting experience

- Restored selected experiments as an alternating editorial archive instead of repeated cards.
- Rebuilt capabilities as connected layers rather than percentages or progress bars.
- Rewrote method and about copy to sound more human and less institutional.
- Ended with a single restrained contact invitation.

## Quality

- Updated metadata and the Open Graph image to the new positioning.
- Updated Playwright tests for the new narrative and interactions.
- Passed TypeScript, ESLint, static links, metadata, confidentiality, hygiene, production build and static WCAG A/AA validation.

## Locked-design 3D and cursor integration

- Preserved every existing section, colour token, typography rule, spacing value, content block and project composition.
- Upgraded the existing `scroll-tech-core.glb` into a continuous scroll-reactive artifact rather than adding a generic decorative model.
- Added section-driven camera movement, mechanical state transitions, orbit geometry, a low-cost particle field, scroll-velocity response and click pulses.
- Connected hover and click intent to the core without making the WebGL canvas interactive or blocking normal page controls.
- Added a non-invasive context cursor that locks onto the existing bounds of links and buttons and displays their accessible text without moving any page element.
- Disabled the custom cursor and live WebGL scene for touch, reduced-motion and lower-capability environments, preserving the original fallbacks.
